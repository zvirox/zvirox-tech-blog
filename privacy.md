      <div class="zv-feature-card" style="margin-bottom:24px;">
        <h3 class="zv-feature-title">2. Easy Edits Pro (Desktop Video Editor)</h3>
        <p class="zv-feature-desc">
          Easy Edits Pro is a local Linux desktop application built with Rust, Tauri, React, and GStreamer.
        </p>
        <ul style="color:var(--zv-text-muted); font-size:14px; line-height:1.7; margin-top:12px; padding-left:20px;">
          <li><strong>Zero telemetry:</strong> Easy Edits Pro sends no usage analytics, tracking pings, or diagnostic telemetry to any remote server.</li>
          <li><strong>Local media processing:</strong> All video rendering, audio timeline mixing, and project files remain strictly on your local storage.</li>
          <li><strong>No accounts:</strong> You do not need to sign up, log in, or register to use the application.</li>
        </ul>
      </div>

      <div class="zv-feature-card" style="margin-bottom:24px;">
        <h3 class="zv-feature-title">3. Audio Labs Pro (Audio Workstation)</h3>
        <p class="zv-feature-desc">
          Audio Labs Pro is an offline-first Linux audio studio built with Rust and iced.
        </p>
        <ul style="color:var(--zv-text-muted); font-size:14px; line-height:1.7; margin-top:12px; padding-left:20px;">
          <li><strong>Offline AI:</strong> Voice cloning, dictation, and speech synthesis models run locally via ONNX runtime on your hardware. Audio recordings and voice profiles never leave your machine.</li>
          <li><strong>Network access:</strong> The application does not connect to the network during normal recording or editing. The only network activity occurs when you explicitly initiate an AI model download.</li>
          <li><strong>Zero telemetry:</strong> No telemetry, analytics, or remote logging.</li>
        </ul>
      </div>

      <div class="zv-feature-card" style="margin-bottom:24px;">
        <h3 class="zv-feature-title">4. Your TV Friend (Android TV Launcher & Debloater)</h3>
        <p class="zv-feature-desc">
          Your TV Friend runs locally on Android TV devices.
        </p>
        <ul style="color:var(--zv-text-muted); font-size:14px; line-height:1.7; margin-top:12px; padding-left:20px;">
          <li><strong>Zero telemetry:</strong> No tracking, no user profiles, and no advertisement identifiers.</li>
          <li><strong>Reversible debloating:</strong> ADB commands disable OEM packages without uninstalling them. No device data is transmitted externally.</li>
          <li><strong>Third-party API widgets:</strong> If you explicitly enable optional launcher widgets, your TV connects directly to public APIs:
            <ul style="margin-top:6px;">

              <li>Recommendations: <a href="https://www.themoviedb.org" target="_blank" rel="noopener noreferrer">The Movie Database (TMDB)</a> metadata API</li>
            </ul>
          </li>
