## Kilo AI: One Open Agent for Every Developer Workflow

Kilo AI (kilo.ai) is an open-source AI coding agent that runs everywhere you write code: VS Code, JetBrains IDEs, CLI, Cloud, Slack, and Mobile. With **500+ models at zero markup**, bring-your-own-keys support, and local model options, it's a model-agnostic alternative to Cursor and other proprietary AI coding tools.

### Core Capabilities

Kilo ships with specialized agents so you can switch contexts without switching tools:

| Agent | What It Does |
|-------|--------------|
| **Code Agent** | Write, refactor, and ship production-ready code with full codebase understanding |
| **Plan Agent** | Plan complex features with structured guidance before writing a single line |
| **Debug Agent** | Identify and fix bugs fast — reads errors, traces issues, suggests fixes |
| **Auto Model** | Routes to Efficient / Frontier / Free model based on budget and task |

### Where You Can Use It

| Surface | How to Get It |
|---------|---------------|
| **VS Code** | Install extension from Open VSX (also works with Cursor, Windsurf) |
| **JetBrains** | Get plugin for IntelliJ, PyCharm, WebStorm |
| **CLI** | `curl -fsSL https://kilo.ai/cli/install \| bash` |
| **Cloud** | Start agents from any browser — Try Cloud free |
| **Slack** | Mention @Kilo in any channel |
| **Mobile** | Follow and review agents from your phone |

### Pricing Philosophy

Kilo's pricing model is built around transparency:

- **Zero markup** on model inference — models at cost
- **Bring your own keys** (BYOK) — use your existing API keys
- **Local models supported** — run models on your own hardware for privacy
- **Free tier** available — no credit card required
- **Enterprise** — free for up to a year for Cursor migrants (promotional)

### Kilo AI vs Cursor

| Feature | Kilo AI | Cursor |
|---------|---------|--------|
| **License** | MIT (open source) | Proprietary |
| **Models** | 500+, zero markup | Limited selection |
| **BYOK** | Yes | Limited |
| **Local models** | Yes | No |
| **IDE support** | VS Code, JetBrains, CLI, Cloud | VS Code only |
| **Open source** | Yes (MIT) | No |
| **Self-hostable** | Yes | No |
| **Pricing** | Models at cost | Subscription + credits |

### Why Kilo? (Design Principles)

Kilo positions itself around three principles, visible throughout the homepage:

1. **Agent command center** — One portal for every agent across IDEs, CLI, and cloud
2. **Aligned pricing** — Models at cost, no markup, no lock-in
3. **Open source** — No black boxes. Audit the prompt, context window, and decisions
